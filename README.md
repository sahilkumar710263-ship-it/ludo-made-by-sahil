# Ludo by Sahil

A browser-based Ludo game built with HTML, CSS, and JavaScript.

## Publish it free with GitHub Pages

1. Sign in to GitHub and create a **new public repository** (for example, `ludo-by-sahil`).
2. Upload `index.html` from this folder to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish the site. The public URL will usually be:
   `https://YOUR-GITHUB-USERNAME.github.io/ludo-by-sahil/`

Replace `YOUR-GITHUB-USERNAME` with your GitHub username and `ludo-by-sahil` with your repository name.

## Notes

- This is a static website; it does not need a server or paid hosting.
- The game can be played in a modern desktop or mobile browser.
- The first publication may take a few minutes.
